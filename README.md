# AI Challenge

Репозиторий заданий AI Advent Challenge #10.
Каждый день — отдельная папка `Day NN` с решением и кратким README.

```
AI Challenge/
├── Day 01/app/   # минимальный запрос к LLM (CLI + web :8000)
├── Day 02/app/   # контроль формата ответа (web :8001 + CLI)
├── .gitignore
└── README.md
```

Провайдер: [ai.wormsoft.ru](https://ai.wormsoft.ru), модель по умолчанию `wormsoft/agent/low`.

Ключ API не коммитится: в каждой папке `app/` создайте `.env` из `.env.example`.
