## Выводы

- Задача с одним ответом: верных из 5 — t=0 → 5, t=0.7 → 5, t=1.2 → 5; сломан формат — 0/0/0.
- Уникальность ответов (exact): t=0 → 1/5 (все одинаковые), t=0.7 → 1/5, t=1.2 → 1/5.
- temperature = 0 на этой модели/маршруте дал стабильно один и тот же верный ответ во всех 5 прогонах.
- Генерация названий: уникальных текстов t=0 → 1/5, t=0.7 → 2/5, t=1.2 → 5/5; средняя Jaccard-схожесть пар 1.0/0.933/0.433; сломан формат списка — 0/0/0.
- Где разнообразие полезно: задача на генерацию (названия) — выше temperature обычно даёт больше разных вариантов. Где вредит: задача с одним правильным ответом — рост temperature повышает шанс уйти от эталона и/или сломать формат ANSWER.
- Практическая рекомендация: для фактов/расчётов/извлечения — temperature ≈ 0; для умеренно творческих текстов — 0.7; для максимального разброса идей — 1.2 (с контролем формата на клиенте).
