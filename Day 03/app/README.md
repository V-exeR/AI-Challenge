# Day 03 — промптинг × рассуждение

Сравнение четырёх способов решения задач через API при двух режимах reasoning.

## Способы

1. Прямой ответ  
2. «Решай пошагово»  
3. Сначала модель пишет промпт, затем им решаем (2 вызова)  
4. Группа экспертов (аналитик / инженер / критик)

## Reasoning

- min: `reasoning.effort = none`
- max: `reasoning.effort = high`

Модель: `wormsoft/agent/low`.

## Запуск web

```powershell
cd "Day 03/app"
python server.py
```

Откройте http://127.0.0.1:8003 — введите API key и запустите эксперимент.
На странице: таблица «способ × рассуждение → верных / токены / время», детали и выводы.
Отчёт также пишется в `experiment_report.md`.

Прогон долгий (~54 запроса к API). Результаты появляются в UI по мере выполнения.
При HTTP 429 сервер ждёт время из ответа API + 2 секунды и повторяет запрос.
